# HotDogPlanet
<img src="https://github.com/yobisaboy/Resume/blob/main/yobisaboyLogo.png" alt="yobisaboy Logo" height="90">

## Introduction
A single-player 2D game themed around hotdogs, ketchup, and mustard, drawing inspiration from the classic *Space Invaders* gameplay.

## Gameplay
- Use arrow keys to move, and the spacebar to shoot.
